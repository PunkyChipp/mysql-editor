01 · WINDOWS PC

Download. Extract. Open one file.

Install Python 3.12 or newer with “Add Python to PATH”, and Docker Desktop. Complete Docker’s first-run setup and any Windows/WSL restart it requests.

Extract the package into a permanent folder in your own Documents folder. Open START STUDY DESK.cmd. A local setup window opens automatically. Create a username and a unique password of at least 12 characters. The launcher prepares the coding tools and MySQL; the first boot can take several minutes.

The PC must stay awake while you use the site. Setup can enable Windows sign-in startup and keep the PC awake while hosting. No router ports need to be opened.

02 · DOMAIN OWNER · ONE TIME

Activate Cloudflare without replacing your website.

Add highereconomicsrevision.co.uk to Cloudflare’s free plan. Import and verify all existing DNS records, then set the Cloudflare-assigned nameservers at your registrar. Cloudflare must report the zone as Active before automatic setup can continue. Keep HTTPS working; use Full (strict) SSL/TLS with the existing GitHub Pages HTTPS origin.

Keep the GitHub Pages website records and custom-domain settings. Preserve email/MX/TXT records and other services. The installer does not change your registrar’s nameservers or import DNS for you. Do not use “reset DNS”.

The current GitHub Pages IPv4 addresses are 185.199.108.153, 185.199.109.153, 185.199.110.153 and 185.199.111.153. Verify them against the records in your own account before activating the switch.

The installer creates a named tunnel, downloads the official connector with SHA-256 verification, installs the API gateway Worker, and adds a route only for highereconomicsrevision.co.uk/mysql-editor/api/*. It enables proxying on the existing website DNS records without changing their addresses. The economics site’s files remain on GitHub Pages.

The API token is discarded after setup and can be revoked once the public connection test succeeds. Connector credentials stay in your Windows user profile and are excluded from downloads and the repository. Review the exact change list in the local window, confirm it, then choose Connect website.

This provisions one personal workspace. Separate student accounts and runtimes need a classroom deployment. Provider free-plan limits apply; the installer does not subscribe to paid plans.

04 · TEST AT HOME, THEN SCHOOL

Test the connection you will actually use.

Once the local window reports a live public connection, open the editor and sign in. At school, use the same link and run this check. Browser API requests stay on this website’s HTTPS origin.

Success at home does not establish that school filtering permits it. If it works at home but is blocked at school, school IT needs to allow the service. After signing in, run SELECT 1; to test an actual database request.

Closing setup does not stop the background backend. Windows shutdown, sleep, stopped Docker or a disconnected tunnel makes the database unavailable. Coursework and MySQL data persist in Docker volumes; export backups before deleting them.
