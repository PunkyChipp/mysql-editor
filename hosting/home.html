LOCAL SETUP · THIS PC ONLY

Your home computer. Your coding desk.

Set this up once. At school, open highereconomicsrevision.co.uk/mysql-editor and sign in.
MySQL and Python run here. The school browser uses your existing website over HTTPS.

Docker Desktop is not installed or is not on PATH. Install Docker Desktop for Windows, restart Windows if requested, then reopen START STUDY DESK.cmd. Your setup settings will be kept.
01 · PRIVATE WORKSPACE

Create your sign-in.

This is the account you use on the editor website. It is separate from GitHub and Cloudflare.

Choose a long, unique password. Its hash is stored in your Windows user profile.

02 · SAME WEBSITE, REAL BACKEND

Connect your domain.

First activate the domain on Cloudflare’s free plan, preserving all its existing DNS records. Open the full setup guide ↗

The token is used in memory for setup, then discarded. Do not paste it into a chat or commit it to GitHub.

  • Create a named outbound tunnel to this PC.
  • Add study-desk-origin.highereconomicsrevision.co.uk.
  • Add a Worker route only for /mysql-editor/api/*.
  • Enable proxying on the existing website DNS records without changing their addresses. Other DNS records and site files stay in place.
